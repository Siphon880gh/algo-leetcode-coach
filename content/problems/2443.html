Given a non-negative integer num, return true if num can be expressed as the sum of any non-negative integer and its reverse, or false otherwise.

Example 1:

Input: num = 443

Output: true

Explanation:

172 + 271 = 443, where 271 is the reverse of 172. Therefore, we return true.

Example 2:

Input: num = 63

Output: false

Explanation:

63 cannot be expressed as the sum of a non-negative integer and its reverse. Therefore, we return false.

Example 3:

Input: num = 181

Output: true

Explanation:

140 + 041 = 181, where 041 represents 41, the reverse of 140. Reversed numbers may contain leading zeros. Therefore, we return true.

Constraints:

  • 0 <= num <= 105
