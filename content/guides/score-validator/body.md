## Simulate

1. score = counter = 0.
2. For each event: stop if counter = 10. "W" → counter + 1; "WD" or "NB" → score + 1; a digit → score + digit.
3. Return [score, counter].

Examples → [12, 1], [10, 0], [0, 10].

Not stopping at 10: example 3 → [0, 11] instead of [0, 10].

Time: O(n)  
Space: O(1)
