## Find the drop

1. Collect indices i with `nums[i] > nums[i + 1]`.
2. None → 0. More than one, or `nums[n − 1] > nums[0]` → −1.
3. Otherwise return `n − i − 1`.

Examples → 2, 0, −1. Checked against trying every shift on 300 random arrays.

Check the wrap: without it example 3 → 2 instead of −1.

Time: O(n)  
Space: O(1)
