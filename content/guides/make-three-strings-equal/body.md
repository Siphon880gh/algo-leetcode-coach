## Common prefix

1. p = length of the longest common prefix of all three.
2. Return −1 if p = 0, else `len1 + len2 + len3 − 3p`.

Examples → 2, −1.

Strings cannot be emptied, so p = 0 means no answer: without that check example 2 → 9 instead of −1.

Time: O(n)  
Space: O(1)
