## Sort squares

1. q = squares of nums, sorted in descending order; h = ⌈n / 2⌉.
2. Return Σ q[:h] − Σ q[h:].

Examples → 12, 16. Checked against trying every order on 1,500 random arrays.

Sorting by value instead of square: example 2 → 0 instead of 16.

Time: O(n log n)  
Space: O(n)
