## Canonical key

1. E = characters at even indices, O = characters at odd indices.
2. Key = (smallest rotation of E, smallest rotation of O), using Booth's algorithm or the two-pointer minimum-rotation scan.
3. Return the number of distinct keys.

Examples → 1, 3, 5. Booth's result matched trying every rotation on 3,000 random strings.

Rotating the whole string: example 1 → 2 instead of 1.

Time: O(total length)  
Space: O(total length)
