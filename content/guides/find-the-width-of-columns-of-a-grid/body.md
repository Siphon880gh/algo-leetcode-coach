## Column maxima

1. For each column `j`: `ans[j] = max over rows of len(str(grid[i][j]))`.
2. Return `ans`.

Examples → [3], [3,1,2].

Converting to text counts the minus sign automatically. Without strings, count digits by repeated division and add 1 for negatives; 0 has length 1.

Time: O(m · n · digits)  
Space: O(n) besides the output
