## Count

1. Return true if every count ≤ 2.

Examples → true, false.

Values seen twice go one to each half; single values fill the gaps, and the halves balance because the length is even.

Counting distinct values is not enough: [1, 1, 1, 2, 3, 4] has 4 distinct values, at least n / 2 = 3, but 1 appears three times → false.

Time: O(n)  
Space: O(n)
