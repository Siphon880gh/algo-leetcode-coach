## Counting sort

1. half = each letter repeated count // 2 times, a to z.
2. Answer half + (the odd-count letter, if any) + reverse(half).

Examples → z, abbba, acddca.

Sorting the whole string: babab → aabbb, which is not a palindrome.

Time: O(n)  
Space: O(n)
