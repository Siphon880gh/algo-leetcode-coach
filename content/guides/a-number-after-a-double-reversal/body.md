## One check

Return `num == 0 or num % 10 != 0`.

Examples → true, false, true.

The first reversal turns trailing zeros into leading zeros, which vanish; the second reversal restores every other digit. 0 is the only number ending in 0 that survives.

Time: O(1)  
Space: O(1)
