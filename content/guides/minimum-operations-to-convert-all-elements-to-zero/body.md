## Increasing stack

1. For each x: pop while top > x.
2. If x > 0 and the stack is empty or top < x: push x and count 1.
3. Answer the count.

Examples → 1, 3, 4. Checked against BFS over every operation on 300 random arrays.

Counting distinct positive values: example 3 → 2 instead of 4.

Time: O(n)  
Space: O(n)
