## Coverage

1. d[l] += 1, d[r + 1] −= 1 for each query; prefix sums give cover[i].
2. Return true if cover[i] ≥ nums[i] for every i.

Examples → true, false.

Comparing totals only: [0, 2] with [[0, 0], [0, 0]] → true instead of false.

Time: O(n + q)  
Space: O(n)
