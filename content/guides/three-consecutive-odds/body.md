## Odd streak

1. `c = 0`; for `x`: `c = c + 1` if `x` is odd, else 0; if `c == 3`, return true.
2. Return false.

`[2,6,4,1]` → false. `[1,2,34,3,4,5,7,23,12]` → true (5, 7, 23).

Do not count odd values in total; they must be consecutive.

Time: O(n)  
Space: O(1)
