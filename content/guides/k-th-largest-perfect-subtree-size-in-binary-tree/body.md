## Post-order sizes

1. go(null) = 0; go(node) = 2s + 1 if both children return the same s ≥ 0, else −1.
2. Record every non-negative size; answer the k-th largest or −1.

Examples → 3, 7, −1.

Counting full subtrees (0 or 2 children everywhere) instead: example 1’s tree with k = 1 → 11 instead of 3.

Time: O(n log n)  
Space: O(n)
