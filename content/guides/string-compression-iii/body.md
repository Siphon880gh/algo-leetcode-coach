## Capped runs

1. From i, extend j while word[j] = word[i] and j − i < 9.
2. Append (j − i) and word[i]; continue from j.

Examples → 1a1b1c1d1e, 9a5a2b.

Without the cap, example 2 → 14a2b.

Time: O(n)  
Space: O(n) for the output
