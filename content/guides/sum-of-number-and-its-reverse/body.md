## Enumerate

1. For `x = 0 … num`: if `x + reverse(x) = num`, return true.
2. Return false.

Examples → true, false, true. Also 0 → true, from 0 + 0.

Reversing drops leading zeros, so 10 reverses to 1, and x can have trailing zeros. Only x ≤ num can work, since the reversal is non-negative.

Time: O(num · digits)  
Space: O(1)
