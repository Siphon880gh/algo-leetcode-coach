## Remainder only

1. `r = 0`.
2. For each digit `d`: `r = (10r + d) mod m`; output 1 if `r = 0`, else 0.

Examples → [1,1,0,0,0,1,1,0,0], [0,1,0,1].

10r + d can reach about 10^10, so use 64-bit before the mod.

Time: O(n)  
Space: O(1) besides the output
