## Every start

1. For each i: o = 0; for j = i, i + 1, …: o |= nums[j]; if o ≥ k, record j − i + 1 and stop.
2. Return the minimum, or −1.

Examples → 1, 3, 1.

The subarray must be non-empty: with k = 0 the answer is 1, not 0 (example 3).

Time: O(n²)  
Space: O(1)
