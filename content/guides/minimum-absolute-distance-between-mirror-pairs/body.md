## One pass

1. last = {}.
2. For j, x: if x in last, best = min(best, j − last[x]); then last[reverse(x)] = j.
3. Return best, or −1.

Examples → 1, 1, −1. Checked against testing every pair on 3,000 random arrays.

Matching in both directions: example 3 → 1 instead of −1.

Time: O(n log max)  
Space: O(n)
