## Cancel against the top

For each character `c`:

- If the stack is non-empty and its top equals `c`, pop.
- Otherwise push `c`.

Return the stack joined into a string.

The final string does not depend on the order of removals, so the left-to-right stack gives the right answer.

Do not repeatedly scan and delete pairs from the string; that is O(n²). A list used as a stack (or the output string builder itself) is enough.

Time: O(n)  
Space: O(n)
