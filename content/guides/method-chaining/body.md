## Chain

1. Return `animals[animals['weight'] > 100].sort_values('weight', ascending=False)[['name']]`.

The example → Tatiana, Jonathan, Tommy, Alex. Checked in pandas 2.2.

The test is strict: `>= 100` would keep an animal weighing exactly 100. Without ascending=False the order is reversed.

Time: O(n log n)  
Space: O(n)
