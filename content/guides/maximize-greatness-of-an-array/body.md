## Two pointers on one array

1. Sort `a`; `i = 0`.
2. For each `x` in `a`: if `x > a[i]`, `i++`.
3. Return `i`.

Examples → 4, 3. Checked against every permutation on 300 random small arrays.

Using a value to beat the smallest beatable target never wastes a larger one, and positions do not matter because perm may be any order.

Time: O(n log n)  
Space: O(1) besides sorting
