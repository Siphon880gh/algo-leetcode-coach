## Count per user

1. `SELECT user_id, COUNT(follower_id) AS followers_count`
2. `FROM Followers GROUP BY user_id ORDER BY user_id`.

Example → 0: 1, 1: 1, 2: 2.

The column name is `followers_count`. Users with no followers do not appear in the table, so they are not reported.

Time: O(rows log rows)  
Space: O(users)
