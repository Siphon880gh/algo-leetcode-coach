## Two checks

1. If n % k ≠ 0, return false.
2. Return max frequency ≤ n / k.

Examples → true, true, false. Checked against trying every grouping on 600 random arrays.

Skipping the frequency check: [1, 1, 1, 2], k = 2 → true instead of false.

Time: O(n)  
Space: O(n)
