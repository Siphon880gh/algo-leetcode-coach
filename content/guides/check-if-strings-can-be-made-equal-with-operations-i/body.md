## Compare pairs

1. Return whether `{s1[0], s1[2]} = {s2[0], s2[2]}` and `{s1[1], s1[3]} = {s2[1], s2[3]}` as multisets.

Examples → true, false. Checked against a search over all swap sequences on 300 random strings.

Comparing all four letters is not enough: example 2 has the same letters but → false.

Time: O(1)  
Space: O(1)
