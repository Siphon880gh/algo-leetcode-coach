## Fix the first element

1. `s = set(nums)`.
2. Return the number of `x ∈ nums` with `x + diff ∈ s` and `x + 2 · diff ∈ s`.

Examples → 2, 2.

Strictly increasing values are distinct, so each value has one index and each x gives at most one triplet. Three pointers moving forward also work in O(n) without the set.

Time: O(n)  
Space: O(n)
