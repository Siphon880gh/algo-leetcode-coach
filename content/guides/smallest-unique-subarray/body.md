## Search the length

1. ok(L): slide a double rolling hash over every window of length L; true if some hash appears once.
2. Binary search the smallest L in [1, n] with ok(L). ok(n) is always true.

Examples → 3, 1, 2. Checked against counting every window directly on 2,000 random arrays.

Searching for a length where every window is distinct: example 2 → 2 instead of 1.

Time: O(n log n)  
Space: O(n)
