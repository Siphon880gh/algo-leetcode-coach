## Kept beans form a rectangle

1. Sort `b`; `total = Σ b`.
2. Return `min(total − b[i] · (n − i))` over `i`.

Examples → 4, 7.

The best level is always some bag's size: raising it to the next bag size keeps the same bags and only adds kept beans. Totals reach 10^10, so use 64-bit.

Time: O(n log n)  
Space: O(1) besides sorting
