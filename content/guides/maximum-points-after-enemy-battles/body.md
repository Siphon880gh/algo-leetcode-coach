## One target

1. m = min(enemyEnergies). If currentEnergy < m, return 0.
2. Return (currentEnergy + sum − m) div m.

Examples → 3, 5. Checked against an exhaustive search on 150 small cases.

Absorbing the weakest too: example 1 → 4 instead of 3. The sum reaches 10^14; use 64-bit.

Time: O(n)  
Space: O(1)
