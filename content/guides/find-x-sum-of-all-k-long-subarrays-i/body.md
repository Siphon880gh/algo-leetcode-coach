## Per-window sort

1. For each window: counts, sorted by (−freq, −value).
2. Add freq · value for the first x.

Examples → [6, 10, 12], [11, 15, 15, 15, 12].

Breaking frequency ties toward the smaller value: example 1 → [6, 7, 12].

Time: O(n · k log k)  
Space: O(k)
