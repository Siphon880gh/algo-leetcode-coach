## Cycle check

1. Return `derived[0] ⊕ derived[1] ⊕ … ⊕ derived[n − 1] = 0`.

Examples → true, true, false. Checked against trying every original on 300 random arrays.

Start with original[0] = 0 and set original[i + 1] = original[i] ⊕ derived[i]; the last condition holds exactly when the total XOR is 0.

Time: O(n)  
Space: O(1)
