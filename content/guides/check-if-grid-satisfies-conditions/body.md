## Check every cell

1. If i + 1 < m and grid[i][j] ≠ grid[i + 1][j], return false.
2. If j + 1 < n and grid[i][j] = grid[i][j + 1], return false.
3. Return true.

Examples → true, false, false.

Time: O(m n)  
Space: O(1)
