## fillna

1. `products['quantity'] = products['quantity'].fillna(0)`; return products.

The example → 0, 0, 779, 849. Checked in pandas 2.2.

Missing values make pandas store the column as float, so the result reads 0.0; add `.astype(int)` if you want integers. fillna on the whole frame would also fill other columns.

Time: O(n)  
Space: O(n)
