## Only three plans

1. `i, j` = sorted indices of the minimum and maximum.
2. Return `min(j + 1, n − i, (i + 1) + (n − j))`.

Examples → 5, 3, 1.

Each deletion removes the first or last element, so the two targets leave either both from the same side or one from each side. With one element, `i = j = 0` and every plan gives 1.

Time: O(n)  
Space: O(1)
