## Simulate

1. active = 0; score = [0, 0].
2. For each i: if nums[i] is odd, swap; if i mod 6 = 5, swap; score[active] += nums[i].
3. Return score[0] − score[1].

Examples → 0, 4, −1.

Skipping the every-6th-game rule: example 2 → 6 instead of 4.

Time: O(n)  
Space: O(1)
