## Enumerate

1. For each l: cnt = value → count, freq = count → number of values.
2. Extend r, updating both maps.
3. Balanced when len(cnt) = 1, or freq has two keys f and 2f.

Examples → 5, 4, 1.

Accepting any single shared count: example 3 → 4 instead of 1.

Time: O(n²)  
Space: O(n)
