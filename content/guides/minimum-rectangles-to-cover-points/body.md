## Sweep x

1. Sort the x values. end = −1; count = 0.
2. For each x > end: count += 1; end = x + w.

Examples → 2, 3, 2. Checked against trying every set of starts on 300 random small cases.

Gaps cost nothing: dividing the span by w + 1 gives x = 0 and 100 with w = 1 → 51 instead of 2.

Time: O(n log n)  
Space: O(n)
