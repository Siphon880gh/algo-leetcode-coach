## Peak split

1. p = index of the maximum.
2. A = Σ nums[0 … p]; B = Σ nums[p … n − 1].
3. Return 0 if A > B, 1 if B > A, −1 if equal.

Examples → 1, 0, −1.

Leaving the peak out of the descending part: example 3 → 0 instead of −1.

Time: O(n)  
Space: O(1)
