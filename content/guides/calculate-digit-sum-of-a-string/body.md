## Repeat until short

While `len(s) > k`: `s = join(str(sum of digits of s[i … i + k))) for i = 0, k, 2k, …)`.

Examples → `135`, `000`.

Example 2 keeps zeros because each block sum 0 becomes the string 0. The length shrinks every round since k ≥ 2.

Time: O(n log n) at most  
Space: O(n)
