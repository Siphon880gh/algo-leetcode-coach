## Counting

1. tot = counts over both arrays; if any is odd, return −1.
2. c = counts in nums1.
3. Return Σ |c[v] − tot[v] / 2| / 2.

Examples → 0, 1, −1. Checked against a BFS over swaps on 600 random cases.

Forgetting to halve the sum: example 2 → 2 instead of 1.

Time: O(n)  
Space: O(n)
