## Stable three-way split

1. Append every `x < pivot` in order.
2. Append every `x == pivot`.
3. Append every `x > pivot` in order.

Examples → `[9,5,3,10,10,12,14]`, `[-3,2,4,3]`.

The usual in-place three-way partition swaps elements and breaks relative order, so it fails the stability rule. Using O(n) extra space is the simple fix.

Time: O(n)  
Space: O(n)
