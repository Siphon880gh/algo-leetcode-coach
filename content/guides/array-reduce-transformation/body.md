## Accumulate

1. `val = init`.
2. For each `x` in `nums`: `val = fn(val, x)`.
3. Return `val`.

Examples → 10, 130, 25. Checked in Node.

The loop never touches fn for an empty array, which gives init as required.

Time: O(n) calls to fn  
Space: O(1)
