## Simulate

1. `seen = {0}`, `p = 0`, `i = 1`.
2. Loop: `p = (p + i · k) mod n`; stop if p is in seen; else add it, `i++`.
3. Return friends (1-indexed) not in seen, in order.

Examples → [4,5], [2,3,4].

At most n distinct receivers exist, so the loop ends within n + 1 passes.

Time: O(n)  
Space: O(n)
