## Lazy reverse

1. Deque d, `rev = false`.
2. For each c: if c is i, flip rev; else append c to the back (or the front when rev).
3. Return d, reversed if rev.

Examples → rtsng, ponter. Checked against reversing directly on 400 random strings.

The letter i itself is never typed. Reversing the whole text each time is O(n²), which is fine for n ≤ 100.

Time: O(n)  
Space: O(n)
