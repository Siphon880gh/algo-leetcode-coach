## Smallest valid value each step

1. `prev = nums[0]`, `ops = 0`.
2. For each next `x`: `prev = max(prev + 1, x)`; `ops += prev − x`.

`[1,1,1]` → 3. `[1,5,2,4,1]` → 14. `[8]` → 0.

Raising an element any higher than `prev + 1` only forces later ones higher too.

Time: O(n)  
Space: O(1)
