## Every start

1. For each i: k = 0.
2. For j = i … n − 1: k += (nums[j] = target); count the subarray if 2 · k > j − i + 1.
3. Return the count.

Examples → 5, 10, 0.

Counting exactly half as a majority: example 1 → 8 instead of 5.

Time: O(n²)  
Space: O(1)
