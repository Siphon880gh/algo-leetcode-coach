## Ternary digits

1. While `n > 0`: if `n % 3 == 2`, return false; `n //= 3`.
2. Return true.

`12 = 110₃` → true. `91 = 10101₃` → true. `21 = 210₃` → false.

Greedy subtraction of the largest power also works, but the digit test is shorter.

Time: O(log₃ n)  
Space: O(1)
