## Largest step first

1. `d = minutes(correct) − minutes(current)`.
2. For `step` in `60, 15, 5, 1`: `ops += d / step`, `d %= step`.
3. Return `ops`.

Examples → 3, 1.

Since each step is a multiple of the next smaller one, greedy is optimal, like coin change with these denominations. correct is never earlier than current, so `d ≥ 0`.

Time: O(1)  
Space: O(1)
