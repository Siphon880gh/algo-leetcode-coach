## Check each artifact

1. `dug` = set of `(r, c)` from `dig`.
2. Count artifacts whose every cell `r1 … r2 × c1 … c2` is in `dug`.

Examples → 1, 2.

Each artifact covers at most 4 cells, so the check is cheap. Artifacts never overlap, so no cell is shared.

Time: O(dig + artifacts)  
Space: O(dig)
