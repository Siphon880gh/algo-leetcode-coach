## Count inversions

1. ones = 0, ans = 0.
2. For each character: if 1, ones += 1; else ans += ones.

Examples → 1, 2, 0.

Each adjacent swap fixes exactly one (1, 0) pair, so the count is the minimum. With n = 10^5 the answer reaches 2.5 · 10^9 (half 1s then half 0s), above 2^31 − 1; use 64-bit.

Time: O(n)  
Space: O(1)
