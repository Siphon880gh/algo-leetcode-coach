## Monotonic stack

1. For each node: pop while the top’s value is smaller than this node’s; push the node.
2. Link the stack from bottom to top and return its bottom.

Examples → [13,8], [1,1,1,1].

Equal values stay, as in Example 2, so pop only on strictly smaller. Reversing the list, keeping values at least the running maximum, and reversing back also works in O(1) extra space.

Time: O(n)  
Space: O(n)
