## Fixed slots

`p = 0`, `q = 1`; for `x` in `nums`: if `x > 0`, `ans[p] = x`, `p += 2`; else `ans[q] = x`, `q += 2`.

Examples → `[3,-2,1,-5,2,-4]`, `[1,-1]`.

Equal counts and a positive start fix every slot's sign, and scanning in order keeps each sign's relative order.

Time: O(n)  
Space: O(n)
