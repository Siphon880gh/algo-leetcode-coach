## Timer handle

1. `id = setTimeout(() => fn(...args), t)`.
2. Return `() => clearTimeout(id)`.

Examples → [{time: 20, returned: 10}], [], [{time: 30, returned: 8}]. Checked in Node with real timers.

Keep the handle in the closure: the cancel function needs it, and clearTimeout on a timer that already ran is harmless.

Time: O(1)  
Space: O(1)
