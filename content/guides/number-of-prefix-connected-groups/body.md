## Counter

1. cnt[w[0 … k − 1]]++ for each word with length ≥ k.
2. Return the number of prefixes with cnt ≥ 2.

Examples → 2, 1, 2.

Counting words in groups instead of groups: example 1 → 4 instead of 2.

Time: O(n · k)  
Space: O(n · k)
