## Walk back

1. i = n − 1.
2. While i > 0 and nums[i − 1] < nums[i]: i−−.
3. Return i.

Examples → 4, 3, 0. Checked against trying every prefix on 2,000 random arrays.

Allowing equal neighbors: example 1 → 1 instead of 4.

Time: O(n)  
Space: O(1)
