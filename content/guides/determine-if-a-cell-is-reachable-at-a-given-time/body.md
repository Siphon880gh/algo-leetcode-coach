## Distance

1. `d = max(|fx − sx|, |fy − sy|)`.
2. If d = 0, return t ≠ 1; else return t ≥ d.

Examples → true, false. Checked against simulating every move on 300 random small cases.

You must move every second: on the target with t = 1 you have to leave, so → false. Without that case it returns true.

Time: O(1)  
Space: O(1)
