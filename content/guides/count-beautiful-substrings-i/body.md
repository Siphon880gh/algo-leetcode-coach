## Enumerate

1. For each i, v = 0; for j ≥ i: update v; c = j − i + 1 − v; count if `v = c` and `v·c mod k = 0`.

Examples → 2, 3, 0. For n up to 5 · 10^4 see part II.

Time: O(n²)  
Space: O(1)
