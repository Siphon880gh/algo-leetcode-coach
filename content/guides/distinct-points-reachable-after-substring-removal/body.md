## Prefix sums

1. P[i] = position after the first i moves.
2. For each start i in 0 … n − k: add P[i + k] − P[i] to a set.
3. Return the size of the set.

Examples → 2, 1, 1. Checked against removing each window and walking on 2,000 random strings.

Counting windows instead of distinct points: example 1 → 3 instead of 2.

Time: O(n)  
Space: O(n)
