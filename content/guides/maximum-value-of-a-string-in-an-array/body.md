## Value per string

1. For each string: if every character is a digit, its value is `int(s)`; otherwise `len(s)`.
2. Return the maximum.

Examples → 5, 1.

00000 is worth 0, not 5. Strings have at most 9 characters, so the largest number, 999,999,999, fits in 32-bit.

Time: O(total length)  
Space: O(1)
