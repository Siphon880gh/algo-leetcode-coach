## Only adjacent non-empty rows connect

1. `prev = 0`, `ans = 0`.
2. For each row with `c > 0` devices: `ans += prev · c`, `prev = c`.

Examples → 8, 0.

A beam needs every row between its ends to be empty, so beams only join consecutive non-empty rows, each device on one with each on the other.

Time: O(m · n)  
Space: O(1)
