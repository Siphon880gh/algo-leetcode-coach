## Count sets

1. For each day, add 1 for each distinct response.
2. Answer the response with the highest count, smallest on ties.

Examples → good, bad.

Counting duplicates within a day: example 1 → ok instead of good.

Time: O(total responses)  
Space: O(distinct responses)
