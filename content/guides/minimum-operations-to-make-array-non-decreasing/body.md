## Sum of drops

1. Return Σ max(0, nums[i − 1] − nums[i]).

Examples → 2, 4. Checked against a shortest-path search over operations on 300 random arrays.

Raising each element to the running max: example 1 → 3 instead of 2.

Time: O(n)  
Space: O(1)
