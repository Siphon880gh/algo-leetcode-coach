## Strip

1. `i = n − 1`; while `num[i] = 0`, move left.
2. Return `num[0 … i]`.

Examples → 512301, 123.

The input has no leading zeros, so at least one non-zero digit remains. Do not convert to a number: up to 1000 digits will not fit.

Time: O(n)  
Space: O(n) for the result
