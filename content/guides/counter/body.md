## Closure

1. `createCounter(n)` returns `() => n++`.

Examples → [10,11,12], [−2,−1,0,1,2]. Checked in Node.

Post-increment returns the old value, so the first call gives n itself. Each counter keeps its own n.

Time: O(1) per call  
Space: O(1)
