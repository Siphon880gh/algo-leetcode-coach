## Leftmost X starts a move

`i = 0`; while `i < n`: if `s[i] == 'X'`, `moves += 1`, `i += 3`; else `i += 1`.

Examples → 1, 2, 0.

Some move must cover the leftmost X; starting it exactly there reaches as far right as possible. Near the end a move can be shifted left to fit, which costs nothing.

Time: O(n)  
Space: O(1)
