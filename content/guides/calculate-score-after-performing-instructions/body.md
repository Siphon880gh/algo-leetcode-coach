## Simulate

1. i = 0, score = 0, seen = {}.
2. While 0 ≤ i < n and i not in seen: mark i; add → score += values[i], i += 1; jump → i += values[i].
3. Answer score.

Examples → 1, 0, 0.

Running the revisited add once more before stopping: example 1 → 4 instead of 1.

Time: O(n)  
Space: O(n)
