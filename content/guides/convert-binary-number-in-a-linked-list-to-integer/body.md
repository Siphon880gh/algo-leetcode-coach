## Horner's rule

1. `v = 0`.
2. For each node: `v = (v << 1) | node.val`.
3. Return `v`.

`[1,0,1]` → 5. `[0]` → 0.

Do not reverse the list first; the head is already the top bit. Do not build a string and parse it; the shift is simpler.

Time: O(n)  
Space: O(1)
