## Slide a fixed shape into the range

1. Running sum `s` from 0; track `mn`, `mx`.
2. Return `max(0, (upper − lower) − (mx − mn) + 1)`.

Examples → 2, 4, 0.

The differences fix the shape; only the starting value is free. The shape's height `mx − mn` must fit inside `[lower, upper]`. Sums of 10^5 differences of 10^5 need 64-bit.

Time: O(n)  
Space: O(1)
