## Two passes

1. cnt = digit counts.
2. For each i: a = s[i], b = s[i + 1]; if a ≠ b, cnt[a] = a and cnt[b] = b, return ab.
3. Return the empty string.

Examples → 23, 21, empty.

Forgetting a ≠ b: 22 → 22 instead of the empty string.

Time: O(n)  
Space: O(1)
