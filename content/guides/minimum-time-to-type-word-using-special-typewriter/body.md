## Sum of arcs

`prev = 'a'`; for each `ch`: `d = |ch − prev|`; `t += min(d, 26 − d) + 1`; `prev = ch`.

`"abc"` → 5. `"bza"` → 7. `"zjpc"` → 34.

Each move is independent, so taking the shorter arc every time is optimal. Typing always costs 1 per character.

Time: O(n)  
Space: O(1)
