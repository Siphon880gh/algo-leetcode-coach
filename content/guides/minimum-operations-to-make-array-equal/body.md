## Closed form

1. Target value = n (the mean of 1, 3, …, 2n − 1).
2. Answer = `Σ_{i < n/2} (n − (2i + 1))` = `(n // 2) · ((n + 1) // 2)`.

n = 3 → 2. n = 6 → 9.

Do not count both halves; each operation fixes one unit on each side at once.

Time: O(1)  
Space: O(1)
