## Scan

1. best = −1.
2. For each i with capacity[i] ≥ itemSize: if best = −1 or capacity[i] < capacity[best], best = i.
3. Return best.

Examples → 2, 0, −1.

Returning the first box that fits: example 1 → 1 instead of 2.

Time: O(n)  
Space: O(1)
