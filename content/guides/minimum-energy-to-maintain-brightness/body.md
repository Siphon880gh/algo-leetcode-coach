## Merge

1. Sort intervals and merge overlapping ones.
2. Return ⌈brightness / 3⌉ · Σ (end − start + 1).

Examples → 14, 2, 4. The bulb count matched searching every bulb set for n ≤ 9.

Skipping the merge: example 3 → 6 instead of 4.

Time: O(m log m)  
Space: O(m)
