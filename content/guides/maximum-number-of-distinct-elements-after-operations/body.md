## Greedy on sorted values

1. Sort; prev = −∞.
2. cur = max(prev + 1, x − k); if cur ≤ x + k, count it and set prev = cur.

Examples → 6, 3. Checked against trying every choice on 300 random small cases.

Skipping the sort: [2, 1, 1], k = 1 → 2 instead of 3.

Time: O(n log n)  
Space: O(1) besides the sort
