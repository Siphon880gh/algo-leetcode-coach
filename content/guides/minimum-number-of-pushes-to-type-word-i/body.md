## Fill 8 keys per layer

1. Return Σ (i / 8 + 1) for i = 0 … n − 1, with integer division.

Examples → 5, 12.

Only keys 2–9 can be remapped, so there are 8 slots per layer; using 9 gives example 2 → 11 instead of 12.

Time: O(n)  
Space: O(1)
