## Grow on the easy ones

Sort; for each `a`: if `mass < a`, return false; `mass += a`. Return true.

Examples → true, false.

Mass only grows, so taking the smallest remaining asteroid is never worse than any other choice. 10^5 asteroids of 10^5 plus the start can reach about 10^10.

Time: O(n log n)  
Space: O(1) besides sorting
