## Post-order

1. dfs(v) returns the subtree maximum.
2. Count v when val ≥ max(dfs(left), dfs(right)) (leaves always count).

Examples → 5, 4.

Requiring a strictly larger value: example 2 → 3 instead of 4.

Time: O(n)  
Space: O(log n), the tree is complete
