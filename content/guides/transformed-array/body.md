## One formula

1. result[i] = nums[((i + nums[i]) mod n + n) mod n].

Examples → [1, 1, 1, 3], [−1, −1, 4].

Using a remainder that can be negative (C or Java %): example 2 at i = 0 gives index −1.

Time: O(n)  
Space: O(n)
