## One distinct value per step

Return the size of `{x ∈ nums : x > 0}`.

Examples → 3, 0. Checked against simulating with x = smallest positive on 200 random arrays.

Subtracting the same x from every positive element keeps distinct values distinct, so at most the values equal to x reach 0 together. x larger than the minimum is not allowed, so each step clears at most one distinct value, and choosing the minimum clears exactly one.

Time: O(n)  
Space: O(n)
