## Exactly once on both sides

`A = Counter(words1)`, `B = Counter(words2)`; return the number of `w` with `A[w] == 1` and `B[w] == 1`.

Examples → 2, 0, 1.

Checking presence alone is not enough: in Example 1, is appears in both arrays but twice in words1.

Time: O(total length)  
Space: O(total length)
