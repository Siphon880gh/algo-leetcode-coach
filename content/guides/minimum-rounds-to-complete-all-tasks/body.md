## Per count

1. Count each difficulty.
2. If any count is 1, return −1.
3. Otherwise sum `(c + 2) / 3`.

Examples → 4, −1.

Remainder 1 turns one 3 into two 2s (3 + 1 = 2 + 2) and remainder 2 adds a single 2, both giving ⌈c / 3⌉.

Time: O(n)  
Space: O(n)
