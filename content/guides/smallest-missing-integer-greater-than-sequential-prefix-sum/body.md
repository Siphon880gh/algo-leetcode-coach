## Prefix sum, then a set

1. s = nums[0]; extend while nums[i] = nums[i − 1] + 1, adding each.
2. S = set(nums); while s ∈ S, s += 1. Return s.

Examples → 6, 15.

The updated title says greater than or equal: example 1’s sum 6 is missing itself, so the answer is 6, not 7.

Time: O(n)  
Space: O(n)
