## Two pointers

1. `i = j = 0`.
2. While both are in range: if `nums1[i] = nums2[j]`, return it; else advance the pointer at the smaller value.
3. Return −1.

Examples → 2, 2.

The smaller value cannot appear later in the other array, since everything ahead there is at least as large. A hash set of one array also works in O(n + m) time but O(n) space.

Time: O(n + m)  
Space: O(1)
