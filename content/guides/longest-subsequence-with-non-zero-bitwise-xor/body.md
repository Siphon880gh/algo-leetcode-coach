## Three cases

1. x = XOR of nums.
2. If x ≠ 0, return n.
3. If some element is non-zero, return n − 1; otherwise return 0.

Examples → 2, 3. Checked against testing every subsequence on 3,000 random arrays.

Returning n − 1 whenever the XOR is 0: [0, 0] → 1 instead of 0.

Time: O(n)  
Space: O(1)
