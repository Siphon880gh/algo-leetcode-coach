## Cheapest bags first

1. `need[i] = capacity[i] − rocks[i]`; sort.
2. For each `d`: if `d > additionalRocks`, stop; else subtract and count.

Examples → 3, 3.

Filling a cheaper bag instead of a dearer one never leaves fewer rocks, so the smallest gaps first maximise the count. Bags that are already full have gap 0 and count for free.

Time: O(n log n)  
Space: O(n)
