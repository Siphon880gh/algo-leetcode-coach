## Two counters

1. cnt[x] = occurrences; ff[c] = number of distinct values with count c.
2. For x in nums: if ff[cnt[x]] = 1, return x.
3. Return −1.

Examples → 30, 20, −1.

Looking for a value that appears once instead: example 1 → 20 instead of 30.

Time: O(n)  
Space: O(n)
