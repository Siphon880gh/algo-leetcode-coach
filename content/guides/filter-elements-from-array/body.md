## Loop and push

1. `out = []`.
2. For `i = 0 … n − 1`: if `fn(arr[i], i)` is truthy, push `arr[i]`.
3. Return `out`.

Examples → [20,30], [1], [−2,0,1,2]. Checked in Node.

Test truthiness, not `=== true`: in Example 3, fn returns n + 1, and only −1 gives 0.

Time: O(n)  
Space: O(n)
