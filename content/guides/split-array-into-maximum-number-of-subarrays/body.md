## Greedy cuts

1. If the AND of all elements is > 0, return 1.
2. Otherwise count each time the running AND becomes 0, then reset it.

Examples → 3, 1. Checked against trying every split on 300 random arrays.

The first case is needed: cutting alone gives example 2 → 0 pieces. Leftover elements after the last cut join the previous piece without raising its AND above 0.

Time: O(n)  
Space: O(1)
