## Bottleneck letter

1. `c` = letter counts of `text`.
2. Return `min(c['b'], c['a'], c['l'] // 2, c['o'] // 2, c['n'])`.

`"loonbalxballpoon"` → 2. `"leetcode"` → 0.

Do not forget to halve l and o. Do not remove letters word by word in a loop; one count is enough.

Time: O(n)  
Space: O(1)
