## Intersect shifted ranges

1. d = original[i] − original[0]; copy[0] must lie in [u − d, v − d].
2. lo = largest left end, hi = smallest right end.
3. Answer max(0, hi − lo + 1).

Examples → 2, 4, 0. Checked against trying every start value on 300 random small cases.

Intersecting the bounds without shifting: example 1 → 0 instead of 2.

Time: O(n)  
Space: O(1)
