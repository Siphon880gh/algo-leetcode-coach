## One pass

1. `mx = 0`, `s = 0`.
2. For each `x`: `mx = max(mx, x)`; `s += x + mx`; output `s`.

Examples → [4,10,24,36,56], [2,4,8,16,32,64].

Values reach 10^9 and there are up to 10^5 of them, so s can reach 2 · 10^14; use 64-bit.

Time: O(n)  
Space: O(1) besides the output
