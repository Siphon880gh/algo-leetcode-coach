## Three cases

1. `n = 1`: return 0.
2. `n` even: return `n / 2`.
3. Otherwise return `n`.

Examples → 2, 3.

For odd n, the slice boundaries sit 360 / n degrees apart and none lies opposite another, so no cut can be a diameter; each of the n boundaries needs its own radius cut. Remember n = 1, where the whole circle is already one slice.

Time: O(1)  
Space: O(1)
