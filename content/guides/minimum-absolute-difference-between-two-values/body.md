## One pass

1. last1 = last2 = none; best = ∞.
2. At a 1: if last2 exists, best = min(best, i − last2); last1 = i. At a 2: the same with last1.
3. Return best, or −1.

Examples → 2, −1. Checked against all pairs on 2,000 random arrays.

Only pairs with the 1 before the 2: example 1 → 3 instead of 2.

Time: O(n)  
Space: O(1)
