## In-degree

1. indeg[v] += 1 for each edge (u, v).
2. If exactly one node has in-degree 0, return it; otherwise −1.

Examples → 0, −1. n = 3 with only edge 0 → 1 gives −1 (teams 0 and 2 both qualify).

An isolated team also has in-degree 0, so it must be counted.

Time: O(n + m)  
Space: O(n)
