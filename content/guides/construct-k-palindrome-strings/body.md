## Two conditions

1. If `k > len(s)`, return false.
2. `odd` = number of letters with odd count; return `odd ≤ k`.

`"annabelle"`, 2 → true. `"leetcode"`, 3 → false. `"true"`, 4 → true.

Do not build the palindromes; the counts decide. Do not forget the length check; each palindrome needs at least one character.

Time: O(n)  
Space: O(26)
