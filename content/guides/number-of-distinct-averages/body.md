## Pair the ends

1. Sort `nums`.
2. For `i < n / 2`: add `nums[i] + nums[n − 1 − i]` to a set.
3. Return the set size.

Examples → 2, 1.

Comparing sums instead of averages avoids floating point. Ties do not matter, since equal values give the same sums whichever copy is removed.

Time: O(n log n)  
Space: O(n)
