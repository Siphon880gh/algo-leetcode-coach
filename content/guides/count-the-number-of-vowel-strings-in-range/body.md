## Direct count

1. For `i = left … right`: count `words[i]` if its first and last characters are both in aeiou.
2. Return the count.

Examples → 2, 3.

A one-letter word like u counts when that letter is a vowel, since it is both first and last.

Time: O(right − left + 1)  
Space: O(1)
