## Level-order search

1. Queue the entrance with distance 0; mark it seen.
2. Pop; for each open, unseen neighbour: if on the border, return distance + 1; else mark and push.
3. Return −1.

Example 1 → 1. Example 2 → 2. Example 3 → −1.

Mark cells when pushed, not when popped, to avoid duplicates. Checking the border on push excludes the entrance automatically.

Time: O(m · n)  
Space: O(m · n)
