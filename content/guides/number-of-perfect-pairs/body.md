## Sort absolute values

1. b = sorted |nums[i]|.
2. For each r, move l right while b[r] > 2 · b[l]; add r − l.
3. Return the total.

Examples → 2, 4, 0. Checked against testing every pair on 3,000 random arrays.

Using the raw values instead of absolute values: example 2 → 1 instead of 4.

Time: O(n log n)  
Space: O(n)
