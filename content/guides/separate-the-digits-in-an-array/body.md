## Concatenate digits

1. For each `x`: append the digits of `x` from left to right.
2. Return the list.

Examples → [1,3,2,5,8,3,7,7], [7,1,3,9].

Pulling digits with mod 10 gives them backwards, so reverse each number’s digits before appending.

Time: O(total digits)  
Space: O(total digits)
