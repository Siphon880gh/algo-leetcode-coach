## Enumerate

1. count = 1 (for 0).
2. For b = 1, 2, …: while 2^b − 1 ≤ n, count++.
3. Return count.

Examples → 2, 3. Checked against a direct check for every n ≤ 1,000.

Forgetting 0: example 1 → 1 instead of 2.

Time: O(log n)  
Space: O(1)
