## Four checks

1. Length ≥ 3.
2. Every character is a letter or a digit.
3. Some character is a vowel (either case) and some is a letter that is not a vowel.

Examples → true, false, false.

Digits are not consonants: counting every non-vowel as one makes a3e valid; it is not.

Time: O(n)  
Space: O(1)
