## Filter by 6

1. For each `x` with `x mod 6 = 0`: `s += x`, `c++`.
2. Return `c = 0 ? 0 : s / c`, rounded down.

Examples → 9, 0.

Guard against dividing by zero, as in Example 2. Values are positive, so integer division rounds down as required.

Time: O(n)  
Space: O(1)
