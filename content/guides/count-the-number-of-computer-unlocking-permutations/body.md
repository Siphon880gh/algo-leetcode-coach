## Check, then factorial

1. If some complexity[i] ≤ complexity[0] for i ≥ 1, return 0.
2. Otherwise return (n − 1)! mod 10^9 + 7.

Examples → 2, 0. Checked against trying every permutation on 200 random arrays.

Allowing complexity[i] = complexity[0]: example 2 → 120 instead of 0.

Time: O(n)  
Space: O(1)
