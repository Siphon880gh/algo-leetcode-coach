## Bounding box

1. r1, r2 = min and max rows with a 1; c1, c2 the same for columns.
2. Return (r2 − r1 + 1) · (c2 − c1 + 1).

Examples → 6, 1.

Forgetting the + 1: example 2 → 0 instead of 1.

Time: O(m n)  
Space: O(1)
