## Try t = 1, 2, …

1. For t = 1, 2, …: if t·k ≥ n or word starts with word[t·k …], return t.

Examples → 2, 1, 4.

Waiting until everything is replaced is not always needed: ⌈n / k⌉ gives example 1 → 3 instead of 2.

Time: O(n² / k)  
Space: O(n)
