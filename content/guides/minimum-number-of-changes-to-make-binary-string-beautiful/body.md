## Pairs

1. Return the number of i with `s[2i] ≠ s[2i + 1]`.

Examples → 2, 1, 0. Checked against a DP over every partition on 500 random strings.

Each mismatched pair needs one change, and one is enough.

Time: O(n)  
Space: O(1)
