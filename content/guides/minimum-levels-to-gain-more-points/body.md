## One pass

1. s_i = 1 if possible[i] else −1; T = Σ s.
2. For i = 0 … n − 2: a += s_i; if a > T − a, return i + 1.
3. Return −1.

Examples → 1, 3, −1.

Bob plays at least one level: letting Alice play all of [1, 1] returns 2 instead of −1.

Time: O(n)  
Space: O(1)
