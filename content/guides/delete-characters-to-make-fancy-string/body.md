## Greedy append

For each `ch`: append unless the result ends with `ch, ch`.

`"leeetcode"` → `"leetcode"`. `"aaabaaaa"` → `"aabaa"`. `"aab"` → `"aab"`.

Every run longer than 2 must lose its extra characters, and keeping exactly two per run is the minimum deletion. Use a list and join once; repeated string concatenation is quadratic in some languages.

Time: O(n)  
Space: O(n)
