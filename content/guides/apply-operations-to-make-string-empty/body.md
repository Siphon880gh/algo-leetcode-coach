## Count and order

1. cnt = letter counts, m = max count, last = last index of each letter.
2. Return the letters with cnt = m, sorted by last.

Examples → ba, abcd. Checked against simulating the rounds on 3,000 random strings.

Order by last occurrence, not first: example 1 → ab instead of ba, because the earlier copies of a are removed first.

Time: O(n)  
Space: O(26)
