## First repeat wins

1. `seen = {}`.
2. For each `c` in `s`: if `c ∈ seen`, return `c`; else add it.

Examples → c, d.

The letter whose second occurrence comes first is exactly the first character you meet that was already seen. A 26-bit mask can replace the set.

Time: O(n)  
Space: O(26)
