## One loser per match

1. Return `n − 1`.
2. Simulation: while `n > 1`: `matches += n // 2`; `n = (n + 1) // 2`.

`n = 7` → 6 (3 + 2 + 1). `n = 14` → 13 (7 + 3 + 2 + 1).

Byes do not add matches; they only delay a team.

Time: O(1)  
Space: O(1)
