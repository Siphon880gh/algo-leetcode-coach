## BFS three times

1. dx, dy, dz = BFS from x, y, z.
2. For each u: (a, b, c) = sorted(dx[u], dy[u], dz[u]); count it when a² + b² = c².
3. Return the count.

Examples → 3, 0, 1.

Requiring all three distances to be positive: example 1 → 0 instead of 3.

Time: O(n)  
Space: O(n)
