## Last 2

1. i = last index of '2'.
2. Return s[0 … i], or "" if there is no 2.

Examples → "1112", "22", "". Checked against every subsequence on 2,000 random strings.

Keeping only the 2s: example 1 → "2" instead of "1112".

Time: O(n)  
Space: O(n)
