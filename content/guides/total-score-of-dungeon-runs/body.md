## Per room

1. D = prefix damage, D[0] = 0.
2. For room i: need = D[i] + req[i] − hp; add i − bisect_left(D[0 … i − 1], need).
3. Return the total.

Examples → 3, 1. Checked against simulating every start on 2,000 random cases.

Testing health before the room’s damage: example 1 → 5 instead of 3.

Time: O(n log n)  
Space: O(n)
