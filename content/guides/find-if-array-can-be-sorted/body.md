## Compare neighbouring runs

1. Split into maximal runs with the same popcount; track each run’s min and max.
2. Return false if some run’s min is below the previous run’s max; else true.

Examples → true, true, false. Checked against bubble-sorting with the allowed swaps on 2,000 random arrays.

In example 3, 3 has two set bits and every other value one, so 3 can never move past 16.

Time: O(n)  
Space: O(1)
