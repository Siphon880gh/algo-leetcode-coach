## Fixed move

1. 75a + 10b = 115 forces a = 1, b = 4.
2. t = min(x, y div 4). Return Alice if t is odd, else Bob.

Examples → Alice, Bob. Checked against a game search for x < 15, y < 40.

Using min(x, y): example 1 → Bob instead of Alice.

Time: O(1)  
Space: O(1)
