## Exchange argument

1. Sort by `growTime` descending.
2. `t += plantTime[i]`; `ans = max(ans, t + growTime[i])`.

Examples → 9, 9, 2. Checked against every planting order on small random inputs.

Total planting time is fixed; only the order matters. Swapping two adjacent seeds so the longer grower goes first never raises the later finish time. Splitting a seed's planting days never helps either.

Time: O(n log n)  
Space: O(n)
