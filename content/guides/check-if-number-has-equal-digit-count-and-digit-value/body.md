## One count

1. `c` = counts of digits 0 … 9.
2. Return true if `c[i] = num[i]` for every `i`.

Examples → true, false.

The string has at most 10 characters, so indices 0 … n − 1 are all digits; digits that never appear as indices do not need checking. In Example 2, digit 0 appears twice but `num[0] = 0`.

Time: O(n)  
Space: O(1)
