## Two directions

1. Swap so that `start ≤ destination`.
2. `cw = sum(distance[start:destination])`, `total = sum(distance)`.
3. Return `min(cw, total − cw)`.

`[1,2,3,4]`, 0 → 3: clockwise 6, the other way 4 → 4.

Do not assume `start < destination`. Do not forget the counter-clockwise route.

Time: O(n)  
Space: O(1)
