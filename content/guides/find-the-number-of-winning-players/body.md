## Pair counts

1. cnt[x][y] += 1 for each pick.
2. Count players x with some cnt[x][y] > x.

Examples → 2, 0, 1.

Counting a player’s balls over all colours: example 2 → 1 instead of 0.

Time: O(picks + n · colours)  
Space: O(n · colours)
