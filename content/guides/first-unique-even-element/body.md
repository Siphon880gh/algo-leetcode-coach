## Count

1. cnt = counts.
2. For x in nums: if x is even and cnt[x] = 1, return x.
3. Return −1.

Examples → 2, −1.

Returning the first even value: example 1 → 4 instead of 2.

Time: O(n)  
Space: O(n)
