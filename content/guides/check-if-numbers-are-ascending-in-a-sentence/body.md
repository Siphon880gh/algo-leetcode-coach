## One pass over tokens

`prev = 0`; for each token `t` that is all digits: if `int(t) ≤ prev`, return false; `prev = int(t)`. Return true.

Examples → true, false, false.

Numbers are positive, so starting `prev` at 0 is safe. Equal neighbours fail because the order must be strictly increasing.

Time: O(n)  
Space: O(n) for the tokens
