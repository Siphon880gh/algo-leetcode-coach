## Ten masks

1. `mask[0 … 9] = 0`; bits R = 1, G = 2, B = 4.
2. For each pair `(color, rod)`: `mask[rod] |= bit[color]`.
3. Return the number of rods with `mask == 7`.

Examples → 1, 1, 0.

Repeated rings of one color on a rod change nothing, which the OR handles for free.

Time: O(n)  
Space: O(1)
