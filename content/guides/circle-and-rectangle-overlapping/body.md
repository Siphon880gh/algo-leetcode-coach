## Clamp

1. `cx = clamp(xCenter, x1, x2)`, `cy = clamp(yCenter, y1, y2)`.
2. Return `(cx − xCenter)² + (cy − yCenter)² ≤ radius²`.

First example → true. Second → false. Third → true (touching counts).

Do not test only the corners; an edge can be closer. Do not use floating square roots; compare squared distances.

Time: O(1)  
Space: O(1)
