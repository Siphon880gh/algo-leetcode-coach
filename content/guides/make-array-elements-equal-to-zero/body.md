## Balance at each zero

1. For each i with nums[i] = 0: L = sum before i, R = total − L.
2. Add 2 if L = R, 1 if |L − R| = 1.

Examples → 2, 0. Checked against simulating every start on 300 random arrays.

Counting only L = R: [1, 0, 0] → 0 instead of 2.

Time: O(n)  
Space: O(1)
