## Running sum

```sql
SELECT person_name
FROM (
  SELECT person_name, turn,
         SUM(weight) OVER (ORDER BY turn) AS total
  FROM Queue
) t
WHERE total <= 1000
ORDER BY turn DESC
LIMIT 1;
```

The first person always fits, so the result is never empty.

Do not order by `person_id`; boarding is by `turn`. Do not use `< 1000`; reaching exactly 1000 kg still fits.

Time: O(n log n)  
Space: O(n)
