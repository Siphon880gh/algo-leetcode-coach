## Sort

1. a ≤ b ≤ c. If a + b ≤ c, return none.
2. a = c → equilateral; a = b or b = c → isosceles; else scalene.

Examples → equilateral, scalene.

Check the triangle first: [2, 2, 5] has two equal sides but is none, not isosceles. [1, 2, 3] is flat, so also none.

Time: O(1)  
Space: O(1)
