## Per count

1. Count values. Any count 1 → −1.
2. Return Σ `(c + 2) // 3`.

Examples → 4, −1. Checked against a DP over counts on 300 random arrays.

Removing pairs only, ceil(c / 2), is too many: example 1 → 5 instead of 4.

Time: O(n)  
Space: O(n)
