## Read the digits

1. For each digit d of n from the left, at place 10^p: if d ≠ 0, append d · 10^p.
2. Return the list, already in descending order.

Examples → [500, 30, 7], [100, 2], [6].

Keeping zero digits: example 2 → [100, 0, 2], and 0 is not a component.

Time: O(log n)  
Space: O(log n)
