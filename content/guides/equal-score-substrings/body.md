## Running sum

1. S = total score; p = 0.
2. For each of the first n − 1 letters: p += its score; if 2 · p = S, return true.
3. Return false.

Examples → true, false. Checked against testing every split on 3,000 random strings.

Checking only the middle split: constructed check (run in code) "aab" → false instead of true.

Time: O(n)  
Space: O(1)
