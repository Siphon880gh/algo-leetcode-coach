## Same or alternating parity

1. e = count of evens, o = count of odds.
2. alt: scan and take each value whose parity differs from the last taken.
3. Return max(e, o, alt).

Examples → 4, 6, 2. Checked against trying every subsequence on 300 random arrays.

Same parity only: example 2 → 4 instead of 6.

Time: O(n)  
Space: O(1)
