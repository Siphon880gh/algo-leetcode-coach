## One pass

1. For `i = 0 … n − 2`: if `nums[i] = key`, `cnt[nums[i + 1]] += 1`.
2. Return the value with the largest count.

Examples → 100, 2.

The target can equal key itself, as in Example 2. Values are at most 1000, so an array of counts also works.

Time: O(n)  
Space: O(n)
