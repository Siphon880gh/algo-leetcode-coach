## Sort by frequency

1. f = letter counts sorted in decreasing order.
2. Return Σ f[i] · (i / 8 + 1).

Examples → 5, 12, 24.

The order matters: putting counts in increasing order gives example 3 → 28 instead of 24.

Time: O(n + 26 log 26)  
Space: O(26)
