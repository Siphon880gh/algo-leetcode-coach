## One array of differences

`d[c] += 1` for `word1`, `d[c] −= 1` for `word2`; return `max |d[c]| ≤ 3`.

Examples → false, true, true.

A single 26-entry array is enough; letters missing from one word count as 0 there.

Time: O(n)  
Space: O(26)
