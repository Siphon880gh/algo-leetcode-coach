## Count and compare

1. For each even `x`: `cnt[x]++`.
2. Return the key with the largest count, the smallest key on ties; −1 if the map is empty.

Examples → 2, 4, −1.

0 is even and counts, so start the answer at −1 rather than 0. Values are at most 10^5, so an array of size 10^5 + 1 works as well as a map.

Time: O(n)  
Space: O(n)
