## Filter on NULL

This assumes unrated books are stored with a NULL rating; take the exact columns from the official statement.

Using the column names the statement gives:

1. `WHERE rating IS NULL`.
2. Order as the statement asks.

Constructed check (run in SQLite): ratings 4.5, NULL, 3.0, NULL for ids 1–4 → ids 2 and 4.

`WHERE rating = NULL` returns no rows.

Time: O(n log n)
