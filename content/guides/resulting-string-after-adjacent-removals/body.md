## Stack

1. For each c: if the stack top t has |t − c| = 1 or 25, pop; else push c.
2. Answer the stack as a string.

Examples → c, "", db. Checked against direct leftmost-pair removal on 1000 random strings.

Forgetting that a and z are neighbours: example 3 → zadb instead of db.

Time: O(n)  
Space: O(n)
