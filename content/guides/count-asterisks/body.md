## Toggle at each bar

1. `inside = false`, `count = 0`.
2. For each character: `|` flips `inside`; `*` adds 1 when `inside` is false.
3. Return `count`.

Examples → 2, 0, 5.

Bars pair up in order, first with second, third with fourth, so a single flag tracks whether you are between a pair. The bar count is even, so the scan always ends outside.

Time: O(n)  
Space: O(1)
