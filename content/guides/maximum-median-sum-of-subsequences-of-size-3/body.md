## Sort

1. Sort nums.
2. Answer Σ nums[i] for i = n/3, n/3 + 2, n/3 + 4, … < n.

Examples → 5, 20. Checked against trying every split into triples on 300 random arrays.

Using consecutive sorted triples: example 1 → 4 instead of 5.

Time: O(n log n)  
Space: O(1) extra
