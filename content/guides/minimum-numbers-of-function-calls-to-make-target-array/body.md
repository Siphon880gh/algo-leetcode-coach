## Two independent costs

1. `adds = Σ popcount(x)`.
2. `doubles = bit_length(max) − 1` (0 if max ≤ 1).
3. Return `adds + doubles`.

`[1,5]` → 5. `[2,2]` → 3. `[4,2,5]` → 6.

Do not count doublings per element; one doubling applies to the whole array.

Time: O(n)  
Space: O(1)
