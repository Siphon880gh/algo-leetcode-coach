## Counter

1. c = counts of nums.
2. Return Σ x · c[x] over x with c[x] % k = 0.

Examples → 16, 0, 12.

Adding each qualifying value once: example 1 → 5 instead of 16.

Time: O(n)  
Space: O(n)
