## Subsequence, not substring

1. If `s` is a palindrome, return 1.
2. Otherwise return 2: remove every `a`, then every `b`.

`"ababa"` → 1. `"abb"` → 2. `"baabb"` → 2.

Do not search for palindromic substrings; a subsequence need not be contiguous. Do not return 0 unless the string is empty (the current constraints keep it non-empty).

Time: O(n)  
Space: O(1)
