## Pair opposite orders

1. Sort processorTime ascending, tasks descending.
2. Return the max of `p[i] + tasks[4i]`.

Examples → 16, 23. Checked against trying every assignment on 60 random small inputs.

Sorting both the same way gives the earliest processor the shortest tasks: example 1 → 18.

Time: O(n log n)  
Space: O(1)
