## Sort pairs, keep names

1. Sort indices `i` by `heights[i]` descending.
2. Return `names[i]` in that order.

Examples → [Mary, Emma, John], [Bob, Alice, Bob].

Names can repeat, as in Example 2, so map from height to name rather than from name to height. Heights are at most 10^5, so a counting sort over heights also works.

Time: O(n log n)  
Space: O(n)
