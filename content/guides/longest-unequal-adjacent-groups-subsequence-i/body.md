## Runs

1. Keep words[i] when i = 0 or `groups[i] ≠ groups[i − 1]`.

Examples → [e, b], [a, b, c]. Any longest answer is accepted; the length matched testing every subsequence on 300 random inputs.

A run of equal groups can contribute only one word, so the answer length is the number of runs.

Time: O(n)  
Space: O(n)
