## Seen set

1. `seen = {}`, `c = 0`.
2. For each word: if its reverse is in seen, `c += 1`; add the word.
3. Return c.

Examples → 2, 1, 0.

Checking the whole set first lets a palindrome such as aa match itself: [aa, bb] → 1 instead of 0. Looking only at earlier words avoids that.

Time: O(n)  
Space: O(n)
