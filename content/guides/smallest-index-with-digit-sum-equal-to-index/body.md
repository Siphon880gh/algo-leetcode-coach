## Scan

1. For i from 0: if digitsum(nums[i]) = i, return i.
2. Return −1.

Examples → 2, 1, −1.

Comparing the value itself with the index: example 2 → −1 instead of 1.

Time: O(n · log max)  
Space: O(1)
