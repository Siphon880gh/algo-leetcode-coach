## Permutations

1. For each of the 6 orders, value = int(join of bin strings, 2).
2. Return the maximum.

Examples → 30, 1296.

Ordering by value, largest first: example 2 → 1058 instead of 1296.

Time: O(1)  
Space: O(1)
