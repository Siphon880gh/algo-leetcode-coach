## One scan

1. For i = 0 … ⌊(n − 1) / 2⌋: if s[i] = s[n − 1 − i], return i.
2. Return −1.

Examples → 1, 1, −1. Checked against scanning every index on 3,000 random strings.

Stopping before the middle (i < ⌊n / 2⌋): example 2 → −1 instead of 1.

Time: O(n)  
Space: O(1)
