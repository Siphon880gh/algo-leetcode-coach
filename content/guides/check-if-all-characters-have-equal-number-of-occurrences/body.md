## Distinct frequencies

Return `len(set(Counter(s).values())) == 1`.

`"abacbc"` → true. `"aaabb"` → false.

Only letters that appear are compared; missing letters do not count as 0. With 26 counters, skip zeros before comparing.

Time: O(n)  
Space: O(26)
