## Range minus set

1. s = set(nums).
2. Return [x for x in min(nums) … max(nums) if x not in s].

Examples → [3], [], [2, 3, 4].

Starting the range at 1: example 2 → [1, 2, 3, 4, 5] instead of [].

Time: O(n + max − min)  
Space: O(n)
