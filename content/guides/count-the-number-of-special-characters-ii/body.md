## Two indices per letter

1. last[c] = last lowercase index, first[C] = first uppercase index.
2. Count c with both present and last[c] < first[C].

Examples → 3, 0, 0.

Use the last lowercase: comparing the first lowercase gives example 3 → 1 instead of 0. Dropping the order check gives 2.

Time: O(n)  
Space: O(26)
