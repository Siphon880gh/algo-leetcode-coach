## Self-views

```sql
SELECT DISTINCT author_id AS id
FROM Views
WHERE author_id = viewer_id
ORDER BY id;
```

The table can repeat rows, and an author can view several of their articles, so `DISTINCT` keeps each id once.

Do not group by article; the output is per author. Do not forget the sort by id.

Time: O(n log n)  
Space: O(authors)
