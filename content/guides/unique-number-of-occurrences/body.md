## Count the counts

1. `c = Counter(arr)`.
2. Return `len(set(c.values())) == len(c)`.

`[1,2,2,1,1,3]` → counts 3, 2, 1 → true. `[1,2]` → counts 1, 1 → false.

Do not check that values are unique; the counts must be. Do not sort and compare neighbours of the array itself.

Time: O(n)  
Space: O(n)
