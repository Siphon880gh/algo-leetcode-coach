## Right to left

1. Return `x => { let v = x; for (let i = functions.length − 1; i ≥ 0; i−−) v = functions[i](v); return v; }`.

Examples → 65, 1000, 42. Checked in Node.

reduceRight does the same in one line. The empty list skips the loop and returns x.

Time: O(n) per call  
Space: O(1)
