## Merge spans

1. last[x] = last index of x.
2. Scan with `end = max(end, last[nums[i]])`; a new block starts when i > end.
3. Return 2^(m − 1) mod 10^9 + 7.

Examples → 8, 1, 2. Checked against trying every partition on 800 random arrays.

Counting distinct values instead of blocks gives example 3 → 4 instead of 2.

Time: O(n)  
Space: O(n)
