## Scan rows

1. `best = [0, −1]`.
2. For each row `i`: `c` = its number of ones; if `c > best[1]`, `best = [i, c]`.
3. Return `best`.

Examples → [0,1], [1,2], [1,2].

Starting the count at −1 makes row 0 win even when every row is all zeros.

Time: O(m · n)  
Space: O(1)
