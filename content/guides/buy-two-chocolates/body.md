## Two minima

1. Find the two smallest prices a ≤ b in one pass.
2. Return `money − a − b` if that is at least 0, else money.

Examples → 0, 3.

If the cheapest pair is unaffordable, every pair is, so no other pair needs checking.

Time: O(n)  
Space: O(1)
